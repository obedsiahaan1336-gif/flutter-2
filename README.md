# w5s2 - Form and Navigation

1. `flutter create .`  (membuat folder android/ios/web dll., tidak menimpa lib/ dan pubspec.yaml)
2. `flutter pub get`
3. `flutter run`

Jika memakai proyek Flutter yang sudah ada: salin folder `lib/` dan `assets/`,
lalu jalankan `flutter pub add flutter_svg` dan daftarkan `assets/icons/` di pubspec.yaml.
